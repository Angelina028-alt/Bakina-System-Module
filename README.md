# Модуль интерфейса оператора

**Студентка:** Бакина А.А.
**Группа:** 5ИТб-2
**Отряд:** 5 — Frontend

## Описание

Фронтенд-модуль для АРМ оператора.

Основные экраны:
- Дашборд (виджеты с метриками)
- Чат с ИИ (трехколоночная верстка)
- Модальное окно (просмотр PDF)

## Скриншоты

| Скриншот | Описание |
|----------|----------|
| dashboard.png | Главный экран с виджетами статистики |
| chat.png | Экран чата: история, диалог, документы |
| modal.png | Модальное окно просмотра документа |

## Структура репозитория

- `docs/сценарии/` — Gherkin-файлы (поведенческие сценарии)
- `docs/макеты/` — скриншоты интерфейсов из Figma
- `src/` — спецификация API (формат OpenAPI)

## Стек технологий

| Технология | Назначение |
|------------|------------|
| React | Библиотека для построения интерфейсов |
| Redux Toolkit | Управление состоянием приложения |
| Ant Design | UI-компоненты (кнопки, таблицы, поля) |
| Axios | HTTP-запросы к бэкенду |
